# Papéis

Perfis de comportamento que você pode pedir a **qualquer** modelo. Em Claude Code eles
podem virar subagentes; em Codex, Copilot ou chat avulso, cole o conteúdo do arquivo
no início da conversa.

| Papel | Quando |
|---|---|
| [`implementador.md`](implementador.md) | escrever código de uma task |
| [`revisor.md`](revisor.md) | revisar diff ou PR |
| [`analista.md`](analista.md) | transformar tarefa do ClickUp em spec, tratar lacunas |

Papel **não substitui** o `CONTEXT.md` — ele soma. Comece pelo contexto, depois o papel.
