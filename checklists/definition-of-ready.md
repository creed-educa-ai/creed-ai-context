# Definition of Ready

Uma tarefa do ClickUp está pronta para começar quando:

- [ ] Tem **ID** e título que descrevem um resultado, não uma atividade.
- [ ] O **valor** está claro: quem usa e para quê.
- [ ] Os **critérios de aceite** existem e são verificáveis (dá para dizer sim/não).
- [ ] Os **repos afetados** estão identificados (back / front / infra).
- [ ] As lacunas de produto viraram **premissa registrada**, não pendência aberta
      (`../conventions/premissas-e-duvidas.md`).
- [ ] As dependências de outras tarefas estão listadas — e não estão bloqueadas.
- [ ] Termo de domínio novo está no `../glossario.md`.

**Não é motivo para adiar:** faltar resposta da cliente. Isso vira premissa e a tarefa
começa. Ver `../conventions/premissas-e-duvidas.md`.
